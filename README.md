## 📝 Descrição
Uma rede social dinâmica desenvolvida para conectar usuários, permitindo o compartilhamento de momentos e pensamentos com base na localização atual do dispositivo.

## 🚀 Funcionalidades
**Autenticação de Usuários**: Sistema seguro para validar e gerenciar o acesso de usuários.
**Feed Dinâmico**: Visualização de postagens de forma organizada e fluida.
**Geolocalização**: Integração com GPS para capturar a localização exata no momento da postagem.
**Interatividade**: Interface intuitiva desenvolvida para proporcionar a melhor experiência de uso.

## 🛠️ Tecnologias Utilizadas
**Linguagem**: Kotlin 
**IDE**: Android Studio 
**Componentes**: ViewBinding, Intents e Integração com GPS
**Layout**: RecyclerView para o Feed

✓ **Concluído**: Protótipo funcional com autenticação, feed e geolocalização integrados.

## 🧠 Aprendizados e Desafios
* Implementação de validação segura de usuários (Auth).
* Manipulação de permissões de tempo de execução para acesso ao GPS.
* Gerenciamento do ciclo de vida da Activity durante a captura de coordenadas.
